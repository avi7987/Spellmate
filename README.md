# Spellmate ♛✨

**שחמט של כישופים**: שחמט פנטזיה לדפדפן. כל כלי הוא דמות מצוירת בתלת-ממד, זז בדיוק כמו בשחמט, ויש לו כוח-על אחד.

🎮 **לשחק עכשיו:** https://avi7987.github.io/Spellmate/
📄 **מסמך האפיון:** https://claude.ai/artifact/HXu7MHfE4DuFUTcmkgh3To

## המשחק

עולם של 30×30 עם ערפל מלחמה, נהר, יערות, גבעות ומכרות קריסטל. לכל ממלכה יש ארמון עם חומות, שער ומגדלי שמירה, והמלך יושב בתוכו.
בכל תור כל יחידה יכולה לזוז פעם אחת, ואז לתקוף או להפעיל כוח. הכורים מייצרים אנרגיה, ובאנרגיה מגייסים דמויות חדשות בשער הארמון.
כל ממלכה מתחילה עם מלך, מכשפה, כורה ושני חיילים. המטרה: לפרוץ לארמון של היריב ולהרוג את המלך.

אפשר לגייס 13 סוגי דמויות: חייל, כורה, קשת, אביר מגן, פרש, מרפאה, מכשפת קרח, קוסם אש, מתנקש, ענק, בליסטרה, דרקון ומכשפה גדולה.

**שליטה:** לחיצה על יחידה מראה לאן היא יכולה ללכת ואת מי לתקוף. WASD או חיצים מזיזים את המצלמה, וגלגלת העכבר מקרבת ומרחיקה. רווח מסיים תור.

## איך לפתוח את הפרויקט במחשב

1. מורידים את [Godot 4.7](https://godotengine.org/download) (חינמי).
2. ב-Godot לוחצים Import ובוחרים את הקובץ `project.godot` מהתיקייה הזו.
3. לוחצים ▶ (F5) כדי לשחק.
