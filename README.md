# Spellmate ♛✨

אסטרטגיית פנטזיה בזמן אמת לדפדפן: ממלכת השמש נגד ממלכת האופל. שולחים קבוצות גיבורים, מטילים קסמים, פורצים את הארמון של היריב ומביסים את המלך שלו.

🎮 **לשחק עכשיו:** https://avi7987.github.io/Spellmate/
📄 **מסמך האפיון:** https://claude.ai/artifact/HXu7MHfE4DuFUTcmkgh3To

## המשחק

- **תורות בבת אחת**: בכל תור יש **שלב תכנון**, ובו הזמן עוצר. בוחרים גיבורים (גרירת ריבוע או לחיצה), שולחים אותם בלחצן ימני, ומוסיפים קלפים וכוחות. אחר כך לוחצים על הכפתור העגול **"בצע!"**, ושני הצדדים פועלים יחד חמש שניות. אחרי כל תור מופיע סיכום.
- **7 עולמות לבחירה**: שדות הממלכה, הביצה (בוץ שמאט), ממלכת האש (לבה שורפת), ממלכת הקרח (מחליקים מהר), המדבר (חול עמוק), ממלכת הממתקים (זעם מתוק) ויער הפטריות הזוהרות (נבגים מרפאים). לכל עולם צבעים, צמחים, אור ומפלצת משלו.
- **בכל מפה**: יערות, אגמים, מכרות קריסטל, מקדשים (מעיין ריפוי, אבן כוח ובאר קסם), תיבות אוצר שמופיעות מדי פעם, ומפלצות במרכז שמגינות על השטח ונותנות פרס.
- **זירת קרב קולנועית**: כשגיבור מביס גיבור, המסך עובר לזירה. הזירה בנויה מהמקום שבו הקרב קרה, ובה רואים את הדו־קרב עם פסי חיים.
- **חפיסה של 8 קלפים**: אפשר לזמן כמה גיבורים מאותו סוג, וכל קלף נטען תוך תור אחד. יש גם קסמים: פצצת קרח, פצצת אש, שיקוי ריפוי וחומת מגן.
- **14 גיבורים** שכל אחד נראה אחרת, ביניהם דרקון גדול עם כנפיים מנפנפות. המלך של האויב מתגרה בכם במהלך הקרב.
- **הכפר**: מבנים שפותחים גיבורים, שדרוגים, קישוטים, חפיסה, תיבות, משימות יומיות, ספר גיבורים, גביעים ו-5 זירות.
- **עיצוב של משחקי מובייל**: אותיות עבות עם קו מתאר, כפתורים צבעוניים, וכל המשחק מימין לשמאל.
- **מוזיקה אבירית**, צלילים וקולות ג׳יבריש מצחיקים. בפעם הראשונה יש קרב הדרכה.

**מצלמה:** WASD, החיצים, עכבר בקצה המסך, או גרירה בלחצן האמצעי. גלגלת העכבר מקרבת ומרחיקה.
**מקשים:** 1-8 לקלפים, Q לכוח, A לבחירת כל הצבא, רווח או Enter לבצע, Esc לביטול.

## איך לפתוח את הפרויקט במחשב

1. מורידים את [Godot 4.7](https://godotengine.org/download) (חינמי).
2. ב-Godot לוחצים Import ובוחרים את הקובץ `project.godot` מהתיקייה הזו.
3. לוחצים ▶ (F5) כדי לשחק.

## קרדיטים

דמויות, נשקים, מבנים ותיבה: [KayKit](https://kaylousberg.com) מאת Kay Lousberg (Adventurers, Skeletons, Medieval Hexagon, Dungeon; רישיון CC0). גופנים: Fredoka, Noto Sans Symbols 2, Noto Emoji (רישיון OFL). הצלילים, המוזיקה והקולות נוצרו בקוד (`tools/make_sounds.py`).
