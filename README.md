# Spellmate ♛✨

אסטרטגיית פנטזיה בזמן אמת לדפדפן: ממלכת השמש נגד ממלכת האופל. שולחים קבוצות גיבורים, מטילים קסמים, פורצים את הארמון של היריב ומביסים את המלך שלו.

🎮 **לשחק עכשיו:** https://avi7987.github.io/Spellmate/
📄 **מסמך האפיון:** https://claude.ai/artifact/HXu7MHfE4DuFUTcmkgh3To

## המשחק

- **תורות סימולטניים**: בכל תור יש **שלב תכנון**, ובו הזמן עומד. בוחרים גיבורים (גרירת ריבוע או לחיצה) ושולחים אותם בלחצן ימני: על הקרקע כדי ללכת, על אויב כדי לתקוף. מתכננים גם קלפים וכוחות. אחר כך לוחצים על החותם האדום **"בצע!"** (או רווח). המחשב מתכנן באותו רגע בלי לראות את התכנון שלכם, ושני הצדדים פועלים יחד 5 שניות. אפשר להריץ מהר או לדלג. ברגעים גדולים יש סצנה קולנועית, ואחרי כל תור מופיע סיכום.
- **חפיסה של 8 קלפים**: גיבורים מופיעים בשער הארמון (כל גיבור פעם אחת, ואם הוא נופל הקלף חוזר אחרי כמה תורות). קלפי קסם: פצצת קרח, פצצת אש, שיקוי ריפוי וחומת מגן.
- **אנרגיה ◆** מגיעה רק מכורים במכרות הקריסטל. בה גם מפעילים כוחות מיוחדים (Q) ומשדרגים את הארמון.
- **המלך** יושב בארמון מוקף חומה, עם שער ושני מגדלים שיורים. אי אפשר לפגוע בו עד שהשער או מגדל נופלים.
- **3 גדלי מפה**: קטנה, בינונית, וגדולה עם ערפל מלחמה.
- **14 גיבורים**, כל אחד נראה אחרת: מלך, מלכה, כורה, חייל, קשת, שומר העצמות, אביר, מרפאה, מכשפת הקרח, קוסם האש, מתנקש הצללים, ענק, בליסטרה, ודרקון גדול עם כנפיים שמנפנפות.
- **הכפר בין הקרבות**: בונים מבנים שפותחים גיבורים, משדרגים ארמון ומכרה, קונים קישוטים, משדרגים גיבורים, בונים חפיסה ופותחים תיבות. יש גביעים ו-5 זירות.
- **ספר הגיבורים**: דף לכל גיבור וקסם, עם תמונה, נתונים, כוח, עצות, ונגד מי הוא חזק או חלש. יש גם דף "איך משחקים".
- **עיצוב של ספר כשפים עתיק**: קלף, דיו וזהב, כותרות בכתב רש"י וחותמות שעווה.
- **מוזיקה אבירית**: תופי מלחמה, חצוצרות ומיתרים בקרב, נבל ותופים שקטים בזמן התכנון, ולאוטה וחליל בכפר. יש גם קולות ג׳יבריש מצחיקים לדמויות.
- **קרב הדרכה** קצר בפעם הראשונה.

**מצלמה:** WASD, החיצים, עכבר בקצה המסך, או גרירה בלחצן האמצעי. גלגלת העכבר מקרבת ומרחיקה.
**מקשים:** 1-8 לקלפים, Q לכוח, A לבחירת כל הצבא, רווח או Enter לבצע, Esc לביטול.

## איך לפתוח את הפרויקט במחשב

1. מורידים את [Godot 4.7](https://godotengine.org/download) (חינמי).
2. ב-Godot לוחצים Import ובוחרים את הקובץ `project.godot` מהתיקייה הזו.
3. לוחצים ▶ (F5) כדי לשחק.

## קרדיטים

דמויות, נשקים, מבנים ותיבה: [KayKit](https://kaylousberg.com) מאת Kay Lousberg (Adventurers, Skeletons, Medieval Hexagon, Dungeon; רישיון CC0). גופנים: David Libre, Noto Rashi Hebrew, Noto Sans Symbols 2, Noto Emoji, Rubik, Suez One, Frank Ruhl Libre (רישיון OFL). הצלילים, המוזיקה והקולות נוצרו בקוד (`tools/make_sounds.py`).
