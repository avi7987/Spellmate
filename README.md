# Spellmate ♛✨

**שחמט של כישופים**: שחמט פנטזיה לדפדפן. כל כלי הוא דמות מצוירת בתלת-ממד, זז בדיוק כמו בשחמט, ויש לו כוח-על אחד.

🎮 **לשחק עכשיו:** https://avi7987.github.io/Spellmate/
📄 **מסמך האפיון:** https://claude.ai/artifact/HXu7MHfE4DuFUTcmkgh3To

## הדמויות

| כלי | דמות | כוח-על |
| --- | --- | --- |
| מלך | המלך הזהוב | **צו מלכותי:** מגן לכלי צמוד |
| מלכה | המכשפה הגדולה | **כישוף קרח:** מקפיא כלי אויב לתור אחד |
| צריח | גולם האבן | **הדף אבן:** דוחף כלי אויב צמוד |
| רץ | הקוסם המסתורי | **שיגור חליפין:** מחליף מקום עם כלי ידידותי |
| פרש | הדרקון הקטן | **נשיפת אש:** הופך משבצת ללבה |
| רגלי | נושא המגן | **הסתערות:** 2 משבצות קדימה מכל מקום |

הפעלת כוח מחליפה את המהלך ועולה אנרגיה. מקבלים +1 אנרגיה בכל תור ו-+1 על כל הכאה.

## מצב הפרויקט

- [x] מנוע חוקים מלא עם בדיקות אוטומטיות
- [x] 6 כוחות-על ומערכת אנרגיה
- [x] משחק מקומי לשני שחקנים ומשחק נגד המחשב (3 רמות)
- [x] ממשק בעברית
- [ ] דמויות תלת-ממד סופיות (כרגע יש דמויות זמניות באותו סגנון)
- [ ] סצנת קרב קולנועית
- [ ] אונליין

## איך לפתוח את הפרויקט במחשב

1. מורידים את [Godot 4.7](https://godotengine.org/download) (חינמי).
2. ב-Godot לוחצים Import ובוחרים את הקובץ `project.godot` מהתיקייה הזו.
3. לוחצים ▶ (F5) כדי לשחק.
