# Spellmate ♛✨

אסטרטגיית פנטזיה בזמן אמת לדפדפן: ממלכת השמש נגד ממלכת האופל. שולחים קבוצות גיבורים, מטילים קסמים, פורצים את הארמון של היריב ומביסים את המלך שלו.

🎮 **לשחק עכשיו:** https://avi7987.github.io/Spellmate/
📄 **מסמך האפיון:** https://claude.ai/artifact/HXu7MHfE4DuFUTcmkgh3To

## המשחק

- **קרב בזמן אמת עם הפסקה**: בוחרים גיבורים (גרירת ריבוע או לחיצה), ושולחים אותם בלחצן ימני על הקרקע או על אויב. הגיבורים תוקפים לבד אויבים שמתקרבים. **רווח** עוצר את הזמן, וגם בזמן ההפסקה אפשר לתת פקודות.
- **חפיסה של 8 קלפים**: גיבורים מזמנים באנרגיה ליד שער הארמון (כל גיבור פעם אחת, ואם הוא נופל הקלף חוזר אחרי זמן קצר). קלפי קסם: פצצת קרח, פצצת אש, שיקוי ריפוי וחומת מגן.
- **אנרגיה ◆** מגיעה רק מכורים שחופרים במכרות הקריסטל. בעזרתה גם מפעילים כוחות מיוחדים (מקש Q) ומשדרגים את הארמון באמצע הקרב.
- **המלך** יושב בארמון מוקף חומה, עם שער ושני מגדלים שיורים. אי אפשר לפגוע בו עד שהשער או אחד המגדלים נופלים.
- **3 גדלי מפה**: קטנה (בערך 4 דקות), בינונית (בערך 8 דקות), וגדולה עם ערפל מלחמה.
- **14 גיבורים שונים**: מלך, מלכה, כורה, חייל, קשת, שומר העצמות, אביר, מרפאה, מכשפת הקרח, קוסם האש, מתנקש הצללים, ענק, בליסטרה ודרקון. לכל אחד כוח מיוחד משלו, ומשפטים מצחיקים עם קול ג׳יבריש.
- **הבסיס בין הקרבות**: כפר תלת-ממדי. בונים מבנים שפותחים גיבורים חדשים, משדרגים את הארמון והמכרה, קונים קישוטים, משדרגים גיבורים (ניסיון + זהב), בונים חפיסה ופותחים תיבות. יש גם גביעים ו-5 זירות שבהן המחשב מתחזק.
- **קרב הדרכה** קצר בפעם הראשונה.

**מצלמה:** WASD או החיצים, עכבר בקצה המסך, או גרירה בלחצן האמצעי. גלגלת העכבר מקרבת ומרחיקה.
**מקשים:** 1-8 לקלפים, Q לכוח, A לבחירת כל הצבא, Esc לביטול, רווח להפסקה.

## איך לפתוח את הפרויקט במחשב

1. מורידים את [Godot 4.7](https://godotengine.org/download) (חינמי).
2. ב-Godot לוחצים Import ובוחרים את הקובץ `project.godot` מהתיקייה הזו.
3. לוחצים ▶ (F5) כדי לשחק.
